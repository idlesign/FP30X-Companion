FP-30X COMPANION

Privacy Policy

Effective date: October 1, 2026

English Русский

FP-30X Companion is an independent Android application for controlling and recording a Roland FP-30X digital piano. This policy explains how the application handles information.

Data collection and sharing

FP-30X Companion does not collect, transmit, sell, or share personal data. The application has no internet permission, contains no advertising or analytics SDK, and does not provide accounts or cloud synchronization.

Data stored on the device

The application stores favorites, presets, the last active preset, and app settings in its private storage. Android may include this private data in the user's encrypted system backup when device backup is enabled.

MIDI and WAV recordings are created only when the user starts recording. They are saved to Downloads or to a folder the user selects through Android's system folder picker. The application does not upload these files. The user can delete recordings with any file manager. Uninstalling the application removes its private data but does not remove recordings in shared storage.

Permissions

  • Nearby devices / Bluetooth: used only to discover and connect to a compatible Bluetooth MIDI device. On Android 11 and earlier, Android requires Location permission for Bluetooth discovery; the app does not obtain or store the user's location.
  • Record audio: used only when the user chooses to record the FP-30X digital audio input over USB. Audio is written locally to a WAV file and is never transmitted. The app checks that Android routed a supported USB audio device rather than the phone microphone.
  • Files and folders: used only to create recordings in Downloads or in a folder selected through Android's system picker.
  • Foreground service: keeps a user-initiated recording active outside the foreground and displays an ongoing notification with a Stop action.

Retention and deletion

No data is kept on a developer-operated server. Users can clear private app data in Android settings or uninstall the application. Recordings in shared storage remain under the user's control and can be deleted with a file manager.

Children

The application is a utility for digital-piano owners and is not directed to children. It does not knowingly collect personal information from children or from any other user.

Changes and contact

If application behavior changes, this policy will be updated before a release that introduces new data handling. Questions can be sent to idlelink@yandex.ru.

FP-30X COMPANION

Политика конфиденциальности

Дата вступления в силу: 1 октября 2026 г.

FP-30X Companion — независимое Android-приложение для управления цифровым пианино Roland FP-30X и записи исполнения. Ниже описано, как приложение обрабатывает информацию.

Сбор и передача данных

FP-30X Companion не собирает, не передаёт, не продаёт и не предоставляет третьим лицам персональные данные. У приложения нет разрешения на доступ к интернету, рекламных и аналитических SDK, аккаунтов и облачной синхронизации.

Данные на устройстве

Избранные тембры, пресеты, последний активный пресет и настройки хранятся в закрытом хранилище приложения. Android может включить эти данные в системную зашифрованную резервную копию, если пользователь включил резервное копирование.

Файлы MIDI и WAV создаются только после запуска записи пользователем. Они сохраняются в Downloads или в выбранную через системный диалог папку и никуда не загружаются. Пользователь может удалить их файловым менеджером. Удаление приложения очищает его закрытые данные, но не удаляет записи из общего хранилища.

Разрешения

  • Устройства поблизости / Bluetooth: только для поиска и подключения совместимого Bluetooth MIDI-устройства. В Android 11 и старше для поиска Bluetooth требуется разрешение «Местоположение», однако приложение не получает и не сохраняет местоположение пользователя.
  • Запись звука: только для выбранной пользователем записи цифрового аудиовхода FP-30X по USB. Звук сохраняется локально в WAV и не передаётся. Приложение проверяет, что Android направил совместимое USB-аудиоустройство, а не микрофон телефона.
  • Файлы и папки: только для создания записей в Downloads или в выбранной пользователем папке.
  • Фоновая служба: продолжает начатую пользователем запись вне активного окна и показывает постоянное уведомление с кнопкой остановки.

Срок хранения и удаление

На сервере разработчика данные не хранятся. Закрытые данные можно удалить в настройках Android или удалив приложение. Записями в общем хранилище управляет пользователь; их можно удалить файловым менеджером.

Дети

Приложение предназначено для владельцев цифрового пианино и не ориентировано на детей. Оно не собирает персональные данные детей или других пользователей.

Изменения и контакты

Если обработка данных изменится, политика будет обновлена до выпуска соответствующей версии. Вопросы можно отправлять на idlelink@yandex.ru.
